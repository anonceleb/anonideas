# Word Entropy Validation System

This folder contains the Java-based entropy validation utilities and documentation.

Files:
- `WordEntropyCalculator.java` — calculates Shannon entropy for word distributions.
- `EntropyValidator.java` — validates entropy scores against theoretical and linguistic bounds.
- `EntropyDemo.java` — demo program showcasing features.
- `EntropyTest.java` — unit tests for the validation code.

Usage (from this folder):
```bash
# Compile
javac WordEntropyCalculator.java EntropyValidator.java EntropyDemo.java EntropyTest.java

# Run demo
java EntropyDemo

# Run tests
java EntropyTest
```
